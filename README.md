# WorldClock

# World Clock System 🌍

A simple World Clock System developed using Java Swing and AWT.

## Features

- Real-time clock
- 4 different time zones
- Automatically updates every second
- Simple GUI
- Uses Swing Timer

## Time Zones

- India - Asia/Kolkata
- London - Europe/London
- New York - America/New_York
- Tokyo - Asia/Tokyo

## Technologies Used

- Java
- Swing
- AWT
- Java Time API
- IntelliJ IDEA
